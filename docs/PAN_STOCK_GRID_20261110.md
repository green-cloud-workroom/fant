# 동결판 재고: 품목 가로·입고일 세로 표

사용자가 승인한 시안을 실제 품목별 재고 탭에 적용한다. 상단 전체 요약은 유지하고 주식·텐더·생식트릿 카테고리를 오른쪽으로 이어 붙인다. 각 품목 아래 열 제목은 `빵(개)`·`동결(판)`으로 한 줄 표시한다.

## 표시와 기능

- 입고일 내림차순으로 날짜별 현재 잔량을 합산한다. 날짜 미상은 별도 마지막 행에 표시한다. 입고 원수량이나 생산일로 바꾸지 않는다.
- 품목별 잔량 합계는 표 상단에 표시한다. 기존 로딩 단계의 closed/remaining 기준과 소수 반올림·상단 요약·실리콘 환산을 유지한다.
- 카테고리 제목을 누르면 해당 열 묶음만 좁은 열로 접힌다. 날짜 행은 모든 카테고리가 공유한다. 좁은 화면은 표 내부에서 가로 스크롤하며 입고일 열은 고정된다.
- 품목명 버튼은 기존 상세 재고와 해당 품목 이력을 연다. 전체 이력·전처리·여러 품목 작업·수동조정·입고·입고 초안·발주 확인·동결가동 흐름은 그대로다.
- 비활성/알 수 없는 품목의 잔량도 `기타 보유 재고`로 표시하여 누락하지 않는다.

## 카테고리 설정

`settings/panStockCategories`: `{version:1, categories:[{id,label}], assignments:[{productName,categoryId}]}`.

문서가 없으면 주식/텐더(텐터 표기 포함)/생식트릿 기본 분류를 사용한다. 설정은 표시용으로만 사용하며 레시피·lot·재고·로그를 변경하지 않는다. 문서 읽기는 기존 settings 권한, 저장 UI와 명령은 admin/office만 허용한다. 설정 저장은 기존 페이지 저장 가드와 Firestore 트랜잭션으로 원본을 비교한다. 다른 사용자 변경 시 덮어쓰지 않고 입력을 보존한다. 빈 카테고리만 삭제할 수 있고 화면에 없는 기존 품목 매핑도 보존한다. 카테고리/품목명 출력은 HTML escape한다.

변경 파일: `src/pages/frozenPan.js`, `src/pages/panStockGrid.js`, `src/pages/panCategoryEditor.js`, `src/frozenPanDesk.css`, `tests/panStockGrid.test.mjs`.

## 검증

- 관련 회귀 테스트 148개 통과, `npm run build` 통과.
- 입고일 최신순·동일 입고일 lot 합산·소수 잔량·날짜 미상·예약어 품목명·표 가로 접기·기존 상세/이력 이동 검사.
- 카테고리 설정만 저장하는 범위·재진입 유지·다른 사용자 수정 충돌·production 계정 저장 거절 검사.
- Chrome 검증용 빌드에서 주식 4종/텐더 3종/생식트릿 5종 가로 배치와 접기, 카테고리 이름 저장, 한 줄 단위 표시를 확인했다.
- 운영 배포 및 실제 계정 화면 증거는 `output/pan-date-grid/`에 기록한다. 실제 재고 수량을 변경하는 확인 작업은 하지 않는다.
