# 직원 알림 표시와 날짜별 기록 연결

2026-11-06 사용자 요청에 따른 직원 표시 수정. 기존 재고·마감 판단은 유지한다.

- `utils/activityDisplay.js`, `utils/staffText.js`: 과거/신규 로그를 품목·작업·수량·단위로 표시. 내부 분류와 취소 원본 경로를 직원 본문에 출력하지 않는다. 이름이 없으면 품목명 확인 필요로 표시하며 임의로 추정하지 않는다. 검색도 표시 문구를 기준으로 한다.
- `manualMovements.js`, `movementForm.js`: 신규 로그에 단위를 포함한다. 빵판 원본 선택 단위를 개로 정정한다. 선택값과 저장 ID, 수량, 취소 연결은 그대로 유지하며 선택지는 날짜·시각·수량·담당·비고·목록 번호로 구별한다.
- `closingChecksLogic.js`, `layout.js`, `pages/main.js`: 미확인 기록 4/5/6번의 판정 기준을 공유하여 해당 날짜만 서버 조회한다. 버튼을 누르면 자동 재포장/생산/사무 미확인 기록 창을 직접 연다. 조회는 확인 처리나 재고 쓰기를 하지 않는다. 원래 확인 절차와 재포장 확인 모달을 재사용한다.
- `correctionDisplay.js`, `inventoryReceiptCorrection.js`, `frozenProduct.js`: 구성품·정정 대상은 이름과 수량으로 표시하고 문의용 추적 번호는 펼쳐보기로 보존한다. 정정/복구 상태 머신과 승인 조건은 변경하지 않는다.
- `statsAutomation.js`, `statsAutomationPreview.js`: 직원 컨펌 본문에서 문서 경로를 빼고 날짜·품목·단위를 우선한다. 검증 화면 문의용 상세와 원본 식별자는 유지한다. 통계 판단, 수신자, 발송 중복 방지 조건은 그대로다.
- 각 메뉴의 오류 표시: 권한/연결/응답 미확정을 한국어로 표시한다. 한국어 업무 안내는 유지하며 결과 미확정 상태에서 재저장을 권하지 않는다.

## 운영 함수 배포 범위

통계 컨펌 본문은 서버에도 존재한다. 현재 배포 소스를 내려받아 `lib/statsAutomation.js` 안의 표시 함수 2개와 이름 대체 문구 2곳, 표시 헬퍼만 교체하는 별도 배포본을 준비한다. 나머지 배포 파일과 발송 설정·트리거·권한은 보존한다. 기존 컨펌을 일괄 수정하거나 알림 함수를 수동 실행하지 않는다. 기존 컨펌은 정상 후속 갱신 시 새 표시 규칙이 적용된다. 최종 배포 검증은 `backend-deployment-verified.json`과 Pages 공개 자산 검증 결과로 별도 확인한다.
