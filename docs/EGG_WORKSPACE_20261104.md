# 계란 현재 재고 + 오늘 입력 — 2026-11-04

선택한 시안에 맞춰 현재 재고와 사용·입고 입력을 나란히 표시한다. 오늘 기록은 최근 50건에서 업무 날짜가 오늘인 개별 기록을 보여주며, 전체 사용 합계나 마감 완료로 해석하지 않는다. 5건씩 넘길 수 있고 기존 7열 입출고 이력은 접힌 영역에 모두 유지한다.

## 변경 범위

- `src/pages/egg.js`: 인라인 사용·입고, 재고 미리보기, 오늘 기록, 접힌 이력. 기존 모달의 저장 본문을 `saveEggEntry`로 공유한다. 마감 확인, 수량 검토, `saveEggChange` → `saveManualMovement`, operationId, expectedBefore, 트랜잭션·로그·권한은 유지한다. 기존 출고의 남은 재고 입력/실사 보정/테스트와 입고 테스트는 기타 입출고에서, 수동조정/취소는 기존 조정 창에서 제공한다.
- `src/style.css`: 계란 화면만 간격·열 배치·반응형을 조정한다.
- `src/utils/formDraft.js`: 새 인라인 폼을 기존 미저장 입력 보호에 포함한다. 모드 전환/모달 진입/화면 이동 때 적용된다.
- `tests/eggWorkspace.test.mjs`: 인라인과 모달의 저장 결과 비교, 지수 표기 수량 정규화, 입력 보존, 기록 페이지, 마감/충돌/초과량, 저장 중 잠금·불명확한 응답 재전송 차단을 검사한다.
- `tests/helpers/eggXssViews.mjs`: 기존 이력 출력 검사의 대상을 접힌 전체 이력 표로 명시한다.

FIFO는 기존 전체 로그 계산을 그대로 사용하며 해당 영역만 갱신하여 입력 DOM을 유지한다. 저장 중에는 입력·모드 전환·다른 저장 창 진입을 잠근다. 성공 후 수량과 비고는 비우고 담당자·선택 날짜는 유지하며, 페이지를 떠나면 다음 진입 날짜는 다시 오늘로 시작한다.

## 검증

- 관련 73개 회귀 검사 통과: 계란 저장/이력/XSS, 신규 화면, 입력 편의, 폼 보호, 마스터 변경, 페이지 자원·실패 처리. 로그: `output/egg-workspace-tests.txt`.
- `npm run build`, `git diff --check` 통과.
- 실제 화면 모듈에 운영 저장을 차단한 로컬 어댑터를 연결해 검증했다. 1024×768에서 주 콘텐츠 clientHeight=scrollHeight=693, 작업 영역 약 513px. 390px 화면은 콘텐츠 clientWidth=scrollWidth=375이며 날짜 필드가 세로 배치된다.
- 기존 입출고·조정 처리 서비스, Firestore Rules, 통계/자동차감 서비스는 변경하지 않았다. 브라우저 운영 저장은 검증 대상으로 사용하지 않는다.
- 운영 배포는 기존 `npm run release:prepare` / `npm run deploy` 검증 발행 경로를 사용한다. 배포·공개 자산 검증 자료는 `output/readpath/`에 남긴다.
