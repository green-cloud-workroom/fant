## 남은 제약과 영향

- 아래 운영 측정은 소수 표본이며 네트워크와 자동화 지연을 포함한다. 일반 사용자의 지속적인 성능 지표를 대체하지 않는다.
- 메인 마감 판정에는 여전히 일부 컬렉션 전체 조회가 한 번 필요하다. 장기간 이력 증가에 대한 날짜 범위/집계 최적화는 별도 변경 범위다.
- 마감 날짜 병렬 탐색은 가장 이른 날짜에서 바로 차단되던 경우 뒤 날짜도 읽는다. 화면 전체의 중복은 제거하지만 모든 데이터 구성에서 동일한 읽기 감소율을 보장하지 않는다.
- 휴일 외 업무 데이터 캐시는 화면 갱신 한 번에 한정된다. 새로 진입하거나 저장·마감 검사를 실행하면 새로 읽는다. 휴일 외부 수정은 최대 30초 캐시 기간이 있다.
- 모의 트랜잭션 검사는 클라이언트 동작 검증이며 실제 다중 사용자 Firestore 경합 검증을 대체하지 않는다. 새 알림 생성 실패는 기록하고 다음 화면 갱신 때 재시도한다.
