# 사무 답변 4건 확정 반영

사용자 지시: “1~3번은 답변대로 반영하고 영양제 3봉은 테스트 맞아.” 현재 재고와 원본은 보존한다. 이번 후속은 로컬 코드·정정 목록·검증에 반영했으며 운영 쓰기·배포·실제 알림은 실행하지 않았다.

## 확정 판단

1. 7/10 고양이 치킨포켓 104,000장: 사무 답변 “실수로 잘못 입력”. 원본 `bagLogs/I6dzV6s0KyCcELmCDPVm`을 입고 통계에서 제외한다. `wvqkhvsSU784UkQ1vXwY` 조정의 -104,000장과 before/after 전량 반전을 근거로 보존한다. 원본·조정·일정·재고는 변경하지 않는다.
2. 9/15 같은 봉투 92,000장 2건: 사무 답변을 사용자가 채택했다. 직접 입력 `F19H7N2xbpLrckgrFiln` 92,000장은 유지하고 예정 완료로 추가된 `4EfX29KrQJas90UmNDID`만 제외한다. 후자는 `stockLedger/5h6Y4H9WyqRPzW6bSo4B`의 직접 참조와 일치한다. 이후 실셈 두 조정(`iA1oTIUx7fbV8ykQpP2Z`, `fHaOsa7LBQ72lZuxtY38`)은 -172,000+80,000=-92,000장으로 후자 추가 직전 잔고까지 이어진다. 중간 +40,000 실셈과 정상 입고는 지우지 않는다. 해당 날짜의 유효 입고 합계는 92,000장이다.
3. 6/9~10/21 봉투 수동차감 75건: 사무 답변 “실셈 후 수량 조절”. `classifyUsage/stockReconciliation`으로 확정하여 원본 차감을 실제 사용량에 더하지 않는다. 기존 자동 차감 합계는 유지한다. 실사 보정을 사용량으로 역산할 수 없으므로 관련 봉투 소진 예측은 자료 부족으로 계속 보류한다. 이 예측 보류는 사무 답변이 미완료라는 뜻이 아니다.
4. 영양제 3봉: 사무 답변은 추정이었으나 사용자가 테스트라고 명시 확정했다. `supplementLogs/7kcg5bvGIop53UeH3oO2`(5/21), `iVJPIuEfoVDbwqzClbQL`(5/23), `h2JLeqd87JalGpQxyqcD`(5/24), 고양이 치킨60용 각 1봉만 `excludeUsage/test`로 분류해 운영 사용 통계에서 제외한다. 다른 정상 영양제 차감과 5/13 편집·삭제 상쇄 기록은 보존한다.

사무 답변 출처: https://docs.google.com/spreadsheets/d/1eGe4pCxwa7tTLpV9mhfC321Mh-2nEyVgHKDxEfSCEtU/edit?gid=0 (시트1 B2:B5). 시트나 답변 내용은 수정하지 않았다.
